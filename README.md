# 📚 Book Management API

A simple **Book Management REST API** built using **Python and FastAPI**.

This project demonstrates basic CRUD-style operations such as adding, viewing, searching, deleting, and updating books using FastAPI.

## 🚀 Features

- ➕ Add a new book
- 📖 Get all books
- 🔍 Search for a book by name
- 🗑️ Delete a book
- 💰 Update the price of a book
- ✅ Input validation using FastAPI type hints
- 📡 REST API endpoints
- 🧪 Interactive API documentation using Swagger UI

## 🛠️ Technologies Used

- Python
- FastAPI
- Uvicorn
- REST API
- In-memory Python list/dictionary
